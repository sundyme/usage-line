# usage-line 发布预告片 · 分镜（v3）

48 秒 · 120 BPM（1 拍 0.5 s，1 小节 2 s）· 1920×1080 · 60 fps

## 用户需求 → 片中的承诺

| 痛点 | 片中怎么讲 |
| --- | --- |
| 想知道还剩多少，得敲 `/usage`、`/context`，打断手上的事 | 开场：命令一条条敲，面板越堆越乱 |
| 离开一会儿，缓存悄悄过期，下一句要重读全部上下文 | 缓存章：倒计时精确到秒，最后一分钟变琥珀色，过期变红；再发一条就重新计时 |
| 写到一半撞上 5 小时额度 | 5h 章：用量与重置倒计时，70% 琥珀色、90% 红色提前提醒 |
| 不清楚这周还剩多少 | 7d 章：一周的节奏，重置时间一目了然 |
| 上下文快满了不自知，模型开始健忘 | 上下文章：占用随对话上涨，`/clear` 立刻归零 |
| 窗口窄、在终端里 | 自适应章：窄窗口自动收起标签，终端里同样原生 |
| 装起来麻烦吗 | 安装章：两行命令，零配置 |

整片的落点：**少一次打断，多一分专注。**

## 语言

- 一个母题贯穿全片：**输入框里的光标**。它打出问题，点燃变化，最后点开链接。
- 元素之间尽量变形而不是硬切：光标变成圆环，圆环排成那一行，那一行的每个圆环又是一章的入口。
- 四章各有自己的色彩世界：缓存蓝、5h 紫、7d 品红、上下文青。章节导航就是 usage-line 那一行本身，放在画面底部。
- 大字只讲一件事，逐字入场时带模糊和位移；重点词用渐变。
- 画面始终在动：镜头缓慢漂移和推进，到交互节点再猛推。
- 不用颗粒、色差和时间码这类修饰。
