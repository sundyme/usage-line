## 视觉

- **产品是平的，影片是玻璃的。** Claude Code 里真实存在的界面，都按 App 原样画成平面的暖灰色。液态玻璃只用在影片自己的动态元素上。开场那条玻璃胶囊落进真实输入框、褪成平面那一刻，就是两者的交接。
- **液态玻璃的做法**：先把背后的画面多级模糊，略提饱和度。只在边缘一圈很窄的弧面上折射，并在那里分出色散虹彩。左上方有一条主发丝高光，右下方有一条较弱的补光，阴影只落在玻璃外面。几块玻璃之间可以用距离场平滑融合。
- 石墨色的影棚背景，只在玻璃需要折射时才铺一层柔和的彩色光。
- 文字两行一组：第一行亮白，第二行灰色，逐字从轻微模糊中升起。关键信息用亮白、较大字号，不让它们退成灰色小字。

## 依据

- Anthropic API 定价：缓存读取 = 基础输入价 × 0.1。
- 缓存 TTL：订阅 1 小时，超额 5 分钟，由插件自动识别。
- 界面数值取自真实的 Claude Code 用量面板：Context window 398.8k / 1M（40%）、Session 9%、Weekly 67%（周五 4:00 重置）。
