# usage-line 发布预告片 · 分镜（v4）

52 秒 · 120 BPM（1 拍 0.5 s，1 小节 2 s）· 1920×1080 · 60 fps

## 用户需求 → 片中的承诺

Claude Code 输入框右下角有个用量图标，点开就能看到上下文和额度。但**点开本身就是一次打断**，而且这个面板里**没有缓存剩余时间**。缓存命中时，重读上下文只按输入价的约一成计费；过期了，下一句就得全价重读。usage-line 把四个数字常驻在输入框上方，不用点开，也不用找。

| 痛点 | 片中怎么讲 |
| --- | --- |
| 想看一眼用量，得点开图标面板，看完再关上，反复打断 | 开场：玻璃面板一次次从图标里弹出、收回 |
| 面板里没有缓存时间 | 面板最后一行是一个红色虚线空位：Prompt cache — — : — — ? |
| 缓存命中省钱，过期了全价重读，却不知道还剩多久 | 为什么章：两根玻璃液柱对比 ×0.1 和 ×1.0；时钟快进到过期，398,800 tokens 全价重读 |
| 不知道该什么时候回来接着聊 | 缓存章：倒计时精确到秒，离开一会儿还剩 12 分钟，回来正好命中；最后一分钟琥珀色，过期变红 |
| 写到一半撞上 5 小时额度，不清楚这周还剩多少 | 额度章：三张玻璃卡片，70% 琥珀、90% 变红，重置时间一并显示 |
| 上下文快满了不自知 | 上下文卡片：涨到 82%，`/clear` 后归零 |
| 窗口窄、在终端里；装起来麻烦吗 | 自适应和安装章：窄窗口自动收起标签；两行命令，零配置 |

整片的落点：**少一次点击，多省一笔 token。**

## 语言

- **液态玻璃**：输入框、弹出面板、usage-line 那一行、缓存圆环的镜片、额度卡片都是同一种玻璃材质。它会折射和模糊背后的画面，边缘带色散虹彩，左上方有一道光。面板从图标里弹性长出，又缩回图标。
- 每一章有自己的色彩世界：开场石墨、为什么章深蓝、过期时转为暗红、缓存蓝、额度紫红青三色。
- 大字只讲一件事，逐字入场时带模糊和位移，重点词用渐变色。
- 音乐和画面同步：缓存一过期，音乐就停；消息一到，缓存重新计时，音乐再起。

## 依据

- Anthropic API 定价：缓存读取 = 基础输入价 × 0.1。
- 缓存 TTL：订阅 1 小时，超额 5 分钟，由插件自动识别。
- 界面数值取自真实的 Claude Code 用量面板：Context window 398.8k / 1M（40%）、Session 9%、Weekly 67%（周五 4:00 重置）。
