# usage-line 发布预告片 · 分镜（v5）

48 秒 · 120 BPM（1 拍 0.5 s，1 小节 2 s）· 1920×1080 · 60 fps

## 讲什么

Claude Code 输入框右下角有个用量图标，点开就能看到上下文和额度。但**点开本身就是一次打断**，而且面板里**没有缓存剩余时间**。缓存命中时，重读上下文只按输入价的一成计费；过期之后，下一句就要全价重读。usage-line 把缓存、5 小时额度、7 天额度和上下文四个数字常驻在输入框上方，不用点开，也不用找。

| 痛点 | 片中怎么讲 |
| --- | --- |
| 想看用量，得点开图标面板，看完再关上 | 开场：真实的 Claude Code 窗口里，用量面板点开、关上、再点开 |
| 面板里没有缓存时间 | 一枚玻璃标注从面板旁浮起：Prompt cache – – : – – ? |
| 缓存命中只花一成，过期全价重读，却不知道还剩多久 | ×0.1 和 ×1 两个大数字，下面一根玻璃时间条慢慢流空 |
| 不知道该什么时候回来接着聊 | 缓存镜头：倒计时精确到秒；离开一会儿还剩 12 分钟，回来发一条消息，正好命中；最后一分钟变琥珀色，过期变红 |
| 撞上额度、上下文快满了却不自知 | 一张倾斜的玻璃桌面上，摆着 5h、7d、上下文三张卡片 |
| 窄窗口、终端 | 真实界面里，窗口变窄时标签依次收起；终端里用饼形字符显示 |
| 装起来麻烦吗 | 两行命令 |

落点：**不用点开，一眼看清。**

## 视觉原则

- **产品是平的，影片是玻璃的。** 凡是 Claude Code 里真实存在的东西，都按 App 原样画：窗口、输入框、用量面板，以及装好之后输入框上方的那一行。用暖灰底色和细描边，不加任何玻璃效果。液态玻璃只用在影片自己的动态元素上：标注、时间条、缓存镜片、额度卡片、片尾的链接。
- **最能说明这条原则的镜头**：一滴玻璃拉伸成胶囊，四个圆环依次落位；然后它落进真实窗口，玻璃褪去，变成 App 里那一行平面的 usage-line。
- **液态玻璃的做法**：先把背后的画面多级模糊，略提饱和度。只在边缘一圈很窄的弧面上折射，并在那里分出色散虹彩。左上方有一条主发丝高光，右下方有一条较弱的补光，阴影只落在玻璃外面。几块形状之间可以用距离场平滑融合，所以一条消息气泡能“流进”缓存镜片。
- 石墨色的影棚背景，只在玻璃需要折射时才铺一层柔和的彩色光。
- 文字两行一组：第一行亮白，第二行灰色。逐字从轻微模糊中升起。
- 转场以模糊推拉、穿越变焦和平推为主，不用故障、马赛克和闪白。

## 依据

- Anthropic API 定价：缓存读取 = 基础输入价 × 0.1。
- 缓存 TTL：订阅 1 小时，超额 5 分钟，由插件自动识别。
- 界面数值取自真实的 Claude Code 用量面板：Context window 398.8k / 1M（40%）、Session 9%、Weekly 67%（周五 4:00 重置）。
